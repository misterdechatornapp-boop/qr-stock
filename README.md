# QR Stock

เว็บแอปสแกน **QR Code / บาร์โค้ด** เพื่อลงทะเบียนสินค้าเข้าคลัง จด note ของแต่ละรหัส และเช็คว่าโค้ดที่สแกนคืออะไร หรือยังไม่เคยลงทะเบียน

**เปิดใช้งาน:** https://misterdechatornapp-boop.github.io/qr-stock/

## ทำอะไรได้บ้าง

- **สแกน** ด้วยกล้องมือถือ, จากรูปภาพ, พิมพ์เอง หรือใช้เครื่องยิงบาร์โค้ด (USB/Bluetooth)
- **เช็คสถานะทันที:** "✓ มีในคลังแล้ว" (แสดงชื่อ จำนวน ที่เก็บ note) หรือ "ยังไม่เคยลงทะเบียน" (มีฟอร์มให้บันทึกเข้าคลัง)
- **QR นี้คืออะไร:** แยกชนิดให้อัตโนมัติ เช่น EAN-13 (ตรวจ check digit + ประเทศ), GS1 (GTIN / Lot / วันหมดอายุ / Serial), URL, PromptPay, Wi-Fi, JSON, ข้อความหลายช่อง
- **กฎการอ่านค่า:** กำหนดเองว่าจะดึงส่วนไหนของโค้ดมาเป็นรหัสสินค้า เช่น ช่องที่ 2 ที่คั่นด้วย `|`, ค่า `?id=` ใน URL, GS1 AI (01), ตัดตามตำแหน่ง, Regex แล้วทดสอบผลได้ทันที กฎนี้ใช้ร่วมกันทุกเครื่อง
- **คลัง:** ค้นหา, แก้ไข/เพิ่ม note, ดูประวัติการสแกนและการแก้ไข, ลบ, Export CSV
- ข้อมูลเก็บใน **Google Sheet** (ชีต `Items`, `Log`, `Config`) ทำให้หลายเครื่องใช้ข้อมูลชุดเดียวกัน

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css`, `app.js` | หน้าเว็บ (GitHub Pages) |
| `rules.js` | ตัวแยกชนิดโค้ด + เครื่องมือกฎการอ่านค่า (pure JS) |
| `sw.js`, `manifest.webmanifest` | ติดตั้งเป็นแอปบนมือถือ / เปิดได้ตอนออฟไลน์ |
| `gas/Code.gs` | Backend: Google Apps Script ที่ผูกกับ Google Sheet |
| `serve.js` | เซิร์ฟเวอร์สำหรับทดสอบในเครื่อง (`node serve.js` → http://localhost:8797) |

## การเชื่อมต่อ

ในหน้าเว็บไม่มี URL หรือรหัสของ backend ฝังไว้ แต่ละเครื่องต้องตั้งค่าเองครั้งแรก โดยไปที่หน้า **สแกน** แล้วสแกน "QR ตั้งค่า" (ผู้ดูแลมีไฟล์นี้อยู่) หรือกรอก URL + API key เองในหน้า **ตั้งค่า**

API key เก็บอยู่ใน Script Properties ของ Apps Script เท่านั้น ไม่มีอยู่ใน repo นี้
